ITI Graduation Project · Lambda + Medallion Architecture

Football Analytics & Live Match Intelligence

Objective: Build an end-to-end Lambda + Medallion pipeline ingesting 3M+ football records from Transfermarkt, delivering both historical analytics and live match simulation.

Approach: Ingested raw data into AWS S3 via a Medallion architecture; modeled into a Galaxy Schema using dbt in Snowflake for analytics-ready reporting. Added a Kafka + Spark Structured Streaming layer to simulate live match events, orchestrated with Airflow.

Outcome: Visualized results via real-time Grafana dashboards for live event monitoring and Power BI dashboards for historical business insights.

ELT Pipeline · Bronze-Silver-Gold Medallion Architecture

Movielens End-To-End Data Pipeline

Objective: Build an end-to-end ELT pipeline on the MovieLens dataset (20M+ ratings, tags, and genome scores) into an analytics-ready data warehouse.

Approach: Followed a Bronze-Silver-Gold Medallion Architecture and modeled a Star Schema with dbt, from AWS S3 into Snowflake. Orchestrated the daily workflow with an Apache Airflow DAG.

Outcome: Delivered a Power BI dashboard surfacing business insights across ratings trends, tag analysis, and genome score distributions.
